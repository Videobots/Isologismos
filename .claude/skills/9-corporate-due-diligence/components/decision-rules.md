# Κριτήρια σημείων απόφασης & όρια βρόχων

> Χρησιμοποιείται από το `/9-corporate-due-diligence`. Κάθε απόφαση γράφεται σε πίνακα `Κανόνας | Αποτέλεσμα (✔/✘/Μ.Ε.) | Τιμή | Πηγή`. «Μ.Ε.» = μη εφαρμόσιμο λόγω έλλειψης πηγής. Δεν μετρά ως επιτυχία και καταγράφεται ως περιορισμός εύρους.
>
> **Placeholder:** τα όρια (ποσοστά, πλήθη) είναι **αρχικές προτάσεις**. Ο χρήστης μπορεί να τα αλλάξει. Κάθε αλλαγή γενικής ισχύος καταγράφεται στο `MEMORY.md` μετά από έγκριση.

---

## 1. `RECON_DEC` — Είναι τα δεδομένα συμφωνημένα;

| # | Έλεγχος | Πηγές που συγκρίνονται | Κριτήριο επιτυχίας |
|---|---|---|---|
| R1 | Ισολογισμός ισοσκελίζεται | Ισολογισμός (PDF) | Σύνολο Ενεργητικού = Ίδια Κεφάλαια + Προβλέψεις + Υποχρεώσεις |
| R2 | Ισολογισμός ↔ Ισοζύγιο | Ισολογισμός ↔ Γενικό Καθολικό / ERP trial balance | Κάθε κονδύλι = άθροισμα των λογαριασμών του |
| R3 | Γενικό ↔ Αναλυτικό Καθολικό | Γενικό ↔ Αναλυτικό Καθολικό | Υπόλοιπο κάθε λογαριασμού = άθροισμα αναλυτικών |
| R4 | Ταμειακά διαθέσιμα ↔ τράπεζα | Λογ. 38 ↔ Bank API / αντίγραφα κίνησης | Υπόλοιπο τέλους χρήσης ανά λογαριασμό (μετά από τεκμηριωμένα reconciling items) |
| R5 | Απαιτήσεις πελατών ↔ CRM | Λογ. 30 (ERP) ↔ CRM (ανοιχτά τιμολόγια / λογαριασμοί) | Σύνολο και 10 μεγαλύτεροι πελάτες |
| R6 | Αποτελέσματα ↔ Καθολικό | Κατάσταση Αποτελεσμάτων ↔ ομάδες 6, 7, 8 | Πωλήσεις, κόστος, αποσβέσεις, φόροι |
| R7 | Συνέπεια περιόδων | Υπόλοιπα έναρξης τρέχουσας = υπόλοιπα λήξης προηγούμενης | Ταύτιση |

**Κανόνας απόφασης:**
- **ΝΑΙ (100% Match):** όλοι οι εφαρμόσιμοι έλεγχοι ✔ και **ανεξήγητη διαφορά = 0** (ανοχή στρογγυλοποίησης ±1 € ανά κονδύλι). Εξηγημένες διαφορές (π.χ. επιταγές σε διαδρομή, τιμολόγια μετά την ημερομηνία αποκοπής) επιτρέπονται **μόνο** αν τεκμηριώνονται με έγγραφο.
- **ΟΧΙ (Ασυμφωνία):** οποιοσδήποτε έλεγχος ✘.
- **Όριο βρόχου `RECON_FIX → ETL`:** 3 κύκλοι. Μετά ρωτάς τον χρήστη (συνέχεια με περιορισμούς / νέος κύκλος / διακοπή).

## 2. `RED_FLAG_DEC` — Εντοπίστηκε κρίσιμος κίνδυνος ή ένδειξη απάτης;

Είσοδος: τα structured outputs του `AN_RISK` (`/5-due-diligence` + `dd-contract-review`).

| # | Κριτήριο κρίσιμου ευρήματος (αρκεί **ένα**) |
|---|---|
| F1 | Ουσιώδες λογιστικό σφάλμα ή ανεξήγητη εγγραφή ≥ **5% των Ιδίων Κεφαλαίων** ή ≥ **2% του Ενεργητικού** (ό,τι είναι μικρότερο) |
| F2 | Μη καταχωρημένες υποχρεώσεις / εγγυήσεις υπέρ τρίτων που εντοπίστηκαν σε συμβάσεις αλλά λείπουν από τον ισολογισμό, ≥ ορίου F1 |
| F3 | Παραβίαση δανειακής ρήτρας (covenant) ή ρήτρα αλλαγής ελέγχου (change of control) που καθιστά δάνειο άμεσα απαιτητό |
| F4 | Ληξιπρόθεσμες οφειλές προς Δημόσιο / ΕΦΚΑ χωρίς ρύθμιση, ή κατασχέσεις / υποθήκες που δεν γνωστοποιούνται |
| F5 | Ενδείξεις χειραγώγησης εσόδων: σημαντικές πιστωτικές εγγραφές πελατών μετά τη λήξη χρήσης, κυκλικές συναλλαγές με συνδεδεμένα μέρη, έσοδα χωρίς αντίστοιχη ταμειακή εισροή |
| F6 | Συναλλαγές με συνδεδεμένα μέρη εκτός συνθηκών αγοράς, ≥ ορίου F1 |
| F7 | Εκκρεμοδικία ή ρυθμιστικό ζήτημα με πιθανή επίπτωση ≥ ορίου F1 ή με κίνδυνο αφαίρεσης άδειας λειτουργίας |
| F8 | Άρνηση ή αδυναμία της διοίκησης να παράσχει βασικά έγγραφα μετά από 3 κύκλους `RECON_FIX` |

**Κανόνες διατύπωσης:** ποτέ «απάτη». Γράφεις «ένδειξη που χρήζει περαιτέρω διερεύνησης (forensic review)». Κάθε F-εύρημα συνοδεύεται από πηγή (αρχείο, σελίδα, λογαριασμό) και ποσό. Πριν οριστικοποιήσεις το «ΝΑΙ», ζητάς επιβεβαίωση από τον χρήστη.

## 3. `GOING_CONCERN_DEC` — Είναι η εταιρεία βιώσιμη (going concern);

**Join:** εκτελείται μόνο όταν υπάρχουν (α) `AN_FIN`, (β) `AN_OP` και (γ) `RED_FLAG_DEC = ΟΧΙ`.

| # | Δείκτης / ένδειξη αδυναμίας συνέχισης | Πηγή |
|---|---|---|
| G1 | Αρνητικά Ίδια Κεφάλαια | AN_FIN |
| G2 | Ίδια Κεφάλαια < ½ Μετοχικού Κεφαλαίου (για Α.Ε., ν. 4548/2018, άρθρο 119 παρ. 4. Για άλλες νομικές μορφές, η αντίστοιχη διάταξη) | AN_FIN |
| G3 | Αρνητικό κεφάλαιο κίνησης **και** αρνητικές λειτουργικές ταμειακές ροές στην τελευταία χρήση | AN_FIN |
| G4 | Net Debt / EBITDA > 6 ή αρνητικό EBITDA | AN_FIN |
| G5 | Δείκτης κάλυψης τόκων (EBIT / τόκοι) < 1 | AN_FIN |
| G6 | Συγκέντρωση: ένας πελάτης > 40% πωλήσεων **και** ενδείξεις απώλειάς του (churn/CRM) | AN_OP |
| G7 | Συνεχόμενες ζημίες σε όλες τις διαθέσιμες χρήσεις, με φθίνουσα τάση πωλήσεων | AN_FIN + AN_OP |
| G8 | Επιφύλαξη ή έμφαση θέματος του ορκωτού ελεγκτή για τη συνέχιση δραστηριότητας | PDF (έκθεση ελεγκτή) |

**Κανόνας απόφασης:**
- **ΟΧΙ (Τεχνική Πτώχευση):** G1 **ή** G8 **ή** τουλάχιστον **3** από τα G2–G7.
- **ΝΑΙ (Υγιής / Αναστρέψιμη):** κανένα από τα παραπάνω.
- **Γκρίζα ζώνη:** 1–2 από τα G2–G7. Η κύρια διαδρομή είναι **ΝΑΙ → DCF**, αλλά ρωτάς τον χρήστη αν θέλει **και** αποτίμηση liquidation ως σενάριο «downside», και το σημειώνεις ως «αναστρέψιμη υπό προϋποθέσεις».

## 4. `REVIEW_DEC` — Εγκρίνεται το προσχέδιο;

- **Ανθρώπινη απόφαση** του Review Partner (εξ ορισμού ο χρήστης). Ερώτηση μέσω AskUserQuestion με επιλογές «Εγκρίνεται» / «Απαιτούνται αλλαγές».
- Σιωπή ≠ έγκριση. Μερική έγκριση («ΟΚ εκτός από…») = «Απαιτούνται αλλαγές».
- **Όριο βρόχου `REVISIONS → SYNTHESIS`:** 3 κύκλοι. Μετά ρωτάς πώς προχωράς.
